## C. LinkedIn project description

I built **SentinelFlow**, a Network Intrusion Detection System simulation for defensive cybersecurity learning. Instead of generating attack packets or touching external networks, it produces realistic synthetic flow records using documentation-only IP ranges. A modular Python pipeline validates records; engineers packet/byte, rate, failure, SYN/RST, and destination-diversity features; applies configurable detection rules; compares traffic to a statistical baseline; and optionally enriches decisions with genuinely trained ML models.

The FastAPI/SQLite backend calculates transparent risk and severity, correlates related alerts, and supports SOC triage with filters, evidence detail, status transitions, notes, and audit history. A React dashboard visualizes traffic, protocols, ports, sources, risk, alert volume, and severity with five-second polling. I evaluated Logistic Regression, Random Forest, and Isolation Forest with held-out metrics and confusion matrices and tested the complete pipeline with 53 automated checks. This project strengthened my Network Security, IDS, SOC, Python, anomaly/signature detection, ML evaluation, security analytics, incident investigation, API, database, testing, and technical-documentation skills.
