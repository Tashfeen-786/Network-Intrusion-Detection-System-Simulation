# Trained Model Artifacts

- `ids_rf.joblib` — selected supervised Random Forest bundle used by the API.
- `ids_logistic.joblib` — supervised Logistic Regression comparison pipeline.
- `ids_isolation.joblib` — unsupervised Isolation Forest comparison pipeline fit on normal training rows.

All artifacts are reproducible from `data/network_traffic.csv` with `python -m ml.train_model`. The bundles must be treated as untrusted binary data if obtained from elsewhere; load only artifacts generated by this repository or a trusted build pipeline.
